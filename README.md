# scnu-ledge-per

> SCNU校团委组织部毕业生转接台账辅助工具（非官方） —— 制作华南师范大学校团委组织部《毕业生学社衔接情况》台账。

## 📖 功能简介
- 当用户提供广东智慧团建系统导出的《毕业生团组织转接统计信息列表》Excel，或提供上一期的转接发起率/完成率统计表与学社衔接情况 Word/PDF，要求生成本期的发起率统计表、完成率统计表、学社衔接情况 Word 与 PDF 时使用。触发词：学社衔接、学社衔接台账、学社衔接情况、转接发起率、转接完成率、智慧团建导出、毕业生团组织转接统计、华师校团委组织部、SCNU校团委组织部。

## 🚀 安装方法

### 手动安装
1. 下载本仓库代码。
2. 将整个 `scnu-ledge-per` 文件夹放入 WorkBuddy 的本地技能目录：
   - **Windows:** `C:\Users\你的用户名\.workbuddy\skills\`
   - **Mac/Linux:** `~/.workbuddy/skills/`
3. 重启 WorkBuddy 会话，技能即可生效。
###作者仅在Workbubby上运行这个skill，其它环境请自行测试

## ⚙️ 环境依赖
本技能依赖以下运行环境，请提前安装：
- **Python 3.8+**
- **依赖库**：如果脚本运行报错提示缺少第三方模块（如 `ModuleNotFoundError`），请在 `scripts/` 目录下安装所需依赖：
  ```bash
  pip install <缺少的库名>

## 💡 使用示例
输入广东智慧团建系统导出的《毕业生团组织转接统计信息列表》Excel，或提供上一期的转接发起率/完成率统计表与学社衔接情况 Word/PDF，并告知上期日期和本期日期，则系统会自动调用本技能中的脚本进行处理。

## ⚠️ 注意事项
- 请确保输入的数据格式符合要求（详细说明见 `references/` 目录）。
- 本技能主要在本地运行，请注意数据安全与备份。
